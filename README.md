# 🎮 Videojuego de Plataformas 2D

## 📖 Descripción
Este proyecto consiste en el desarrollo de un videojuego de plataformas en 2D realizado con **Unity y C#**.

El jugador debe superar diferentes niveles, evitar enemigos y obstáculos, recoger monedas y alcanzar los objetivos para avanzar en el juego.

El proyecto está desarrollado como práctica de programación y desarrollo de videojuegos, aplicando conceptos de físicas, colisiones, interfaces gráficas y gestión de escenas.

## 🕹️ Características principales

- **Movimiento del jugador:** desplazamiento horizontal.
- **Saltos:** salto normal y doble salto con temporizador.
- **Monedas:** recogida de objetos y sistema de puntuación.
- **Enemigos:** movimiento de patrulla para dificultar el recorrido.
- **Sistema de vidas:** el jugador comienza con 3 vidas en modo de una única barra de vida.
- **Barra de vida:** muestra visualmente las vidas restantes.
- **Invulnerabilidad temporal:** después de recibir daño, el jugador es invulnerable durante 1,5 segundos y parpadea.
- **Sistema de Game Over:** aparece cuando el jugador pierde todas sus vidas.
- **Sistema de victoria:** permite completar el nivel al alcanzar el objetivo.
- **Sonido y música:** música de fondo y efectos de sonido para diferentes acciones.
- **Menú de pausa:** permite pausar, reanudar y reiniciar la partida.
- **Sistema de puntuación:** guarda y transfiere los puntos entre niveles.

## 🎮 Controles

| Acción | Control |
|---|---|
| Moverse a la izquierda | Tecla A / Flecha izquierda |
| Moverse a la derecha | Tecla D / Flecha derecha |
| Saltar | Barra espaciadora / Tecla W / Flecha arriba
| Pausar el juego | ESC |


## 🛠️ Tecnologías utilizadas

- **Unity:** motor de desarrollo del videojuego.
- **C#:** lenguaje de programación.
- **Unity 2D Physics:** gestión de físicas y colisiones.
- **Unity UI:** creación de menús y barras de vida.

## 🏁 Objetivo del juego

Superar los dos niveles, recoger 10 monedas para conseguir la puntuación necesaria para abrir la puerta y encontrar la meta mientras evitas los peligros del escenario.

## 🚀 Instalación y ejecución

1. Descarga o clona este repositorio.
2. Abre Unity Hub.
3. Selecciona **Add Project from Disk**.
4. Busca la carpeta del proyecto.
5. Ábrelo con la versión de Unity utilizada para desarrollarlo.
6. Abre la escena inicial y pulsa Play.
